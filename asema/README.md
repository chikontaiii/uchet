# Учёт имущества колледжа — HTML + CSS + JS + MySQL (онлайн)

Сайт на чистом JavaScript, сервер Node.js + Express, база данных MySQL (локальная или облачная).
Права проверяются на сервере, пароли хранятся хешами (bcrypt), сессии лежат в MySQL.

## Возможности
Имущество (поиск, фильтры, страницы, добавление, изменение, перемещение с историей, статусы, этикетка с QR-кодом),
кабинеты, преподаватели, заявки на ремонт, **инвентаризация кабинетов** (с печатью акта),
**списание с причиной и актом**, отчёты (Excel/CSV, печать), **управление пользователями**, смена пароля,
журнал действий, светлая и тёмная тема. Роли: администратор, техник, преподаватель.

## 1. База данных онлайн
Создайте MySQL-базу у облачного провайдера (например TiDB Cloud, Aiven, Railway) и скопируйте строку подключения
или параметры host, port, user, password, database.

## 2. Запуск (каждая команда отдельно, в папке с package.json)
1. Скопируйте `.env.example` в `.env` и заполните: либо `DATABASE_URL=...`, либо `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` и `DB_SSL=true`. Задайте `SESSION_SECRET`.
2. `npm install`
3. `npm run db:setup` — создаст таблицы и тестовые данные в онлайн-базе (старые данные в них удалятся!)
4. `npm start`, затем http://localhost:3000

Вход: `Асема` / `Асема321` (администратор), `tech` / `1234`, `teacher` / `1234`. Смените пароли после первого входа.

## 3. Сайт онлайн (Render)
1. Загрузите проект на GitHub (файл `.env` не загружается — он в `.gitignore`).
2. Render → New → Web Service → ваш репозиторий. Build: `npm install`, Start: `npm start`.
3. В Environment добавьте: `DATABASE_URL` (или `DB_*` + `DB_SSL=true`), `SESSION_SECRET`, `NODE_ENV=production`.
4. Таблицы создайте один раз с компьютера командой `npm run db:setup` (в `.env` — данные онлайн-базы).

`/health` отвечает `ok` — удобно для проверки хостинга.
